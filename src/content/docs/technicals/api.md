[ORD.NET](https://ord.net) exposes a wallet-authenticated trading API.

There are no API keys. A wallet signs a challenge to receive a bearer token, and the signing payment
address must hold at least `0.01 BTC` confirmed for the token to issue.

Full reference: [developers.ord.net](https://developers.ord.net/).
